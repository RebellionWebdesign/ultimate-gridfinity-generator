# Gridfinity reference drawings

Eleven technical drawings (SVG, A4, scale and unit in each title block) of the Gridfinity bin and baseplate: profiles, widths, radii, stacking lip, total height. They hold the complete dimensions and are the dimension reference for agents (`skills/gridfinity-spec/SKILL.md`). Agents never edit them.

- **Author:** Stu142, drawings dated 2023-11-10, made in FreeCAD.

- Each file embeds the author's logo as a PNG, so they are large (0.6 to 2.2 MB).
